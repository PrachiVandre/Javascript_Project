# 🔥 JavaScript Mini Projects & Components

This repository contains a collection of mini JavaScript and React-based components, built for practicing UI, DOM manipulation, logic building, and state management.

---

## 📁 List of Projects

| Project Name             | Description                                      |
|--------------------------|--------------------------------------------------|
| Dad Jokes                | Fetches random jokes using an API                |
| Event_KeyCodes           | Shows key codes when keys are pressed            |
| Expanding_Cards          | Interactive expanding image cards                |
| Hidden Search Widget     | UI for expanding search bar                      |
| Movie_app                | Basic movie list with search (API-based)         |
| Progress_Steps           | Step-by-step progress tracker UI                 |
| QuizApp                  | Simple multiple-choice quiz with score counter   |
| Quotes_generator         | Generates random quotes (with API)               |
| Random Color Generator   | Button to generate and display random colors     |
| RandomPassword           | Generates random passwords using character sets |
| Recipe App               | Displays recipes based on ingredient input       |
| Shopping Cart            | Add/remove items, calculate total                |
| TODO                     | Basic Todo list with add/delete task             |
| Typing Games             | Typing speed test using JavaScript               |

---

## 🛠️ Tech Stack

- HTML / CSS / JavaScript
- React (for a few components)
- Fetch API
- LocalStorage (for persistence where applicable)
